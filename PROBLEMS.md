# Movie Database Problems

Create a separate page for each problem, named **Problem 1** through **Problem 8**. Edit only `app.js`. Each page should display one card per movie, showing only the information requested.

Ratings are out of **5**. A movie can belong to more than one genre. When two movies have the same value for your main sorting choice, sort them alphabetically by title, then by movie ID. If fewer movies match than the requested maximum, show all the matching movies.

## Problem 1: Movies from 2000

Find movies released in **2000**. Display each movie's **title and year**. Sort alphabetically by title and show up to **12 movies**.

## Problem 2: Highest-rated comedies

Find movies whose genres include **Comedy**. Display each movie's **title and rating**. Sort from highest rating to lowest and show up to **5 movies**.

## Problem 3: Highest-rated horror movies

Find movies whose genres include **Horror** and that have at least **20 ratings**. Display each movie's **title, year, and rating**. Sort from highest rating to lowest and show up to **5 movies**.

## Problem 4: Comedies from 2000

Find movies released in **2000** whose genres include **Comedy**. Display each movie's **title, year, and rating**. Sort alphabetically by title and show up to **8 movies**.

## Problem 5: Recent horror

Find horror movies released in **2010 or later** with at least **20 ratings**. Display each movie's **title, year, rating, and number of ratings**. Sort from newest release year to oldest and show up to **5 movies**.

## Problem 6: Highly rated older movies

Find movies released **before 1990** with a rating of at least **4** and at least **50 ratings**. Display each movie's **title, year, and rating**. Sort from highest rating to lowest and show up to **10 movies**.

## Problem 7: Horror comedies

Find movies whose genres include **both Horror and Comedy** and that have at least **10 ratings**. Display each movie's **title, genres, and rating**. Sort from highest rating to lowest and show up to **5 movies**.

## Problem 8: A decade of movies

Find movies released from **2000 through 2009**, including both years, with at least **50 ratings**. Display each movie's **title, year, and number of ratings**. Sort from the largest number of ratings to the smallest and show up to **5 movies**. This question is about how many ratings a movie received, not its average rating.
